## Rulings made in this plan

- **GAP-037, private channels:** Admins don't manage private channels they aren't in.
  - Managing a channel (edit, archive) needs the new action `channel.manage`. That means a member of the channel, or an Admin for a public channel.
  - A private channel you aren't in answers 403 "You're not in this channel.", as reading it already does.
  - Channel names stay unique across the workspace, hidden ones included. A clash now reads `That name is taken.` whether the other channel is visible or not, so the copy no longer says a channel exists.
- **GAP-042, Database page:**
  - "Reload seed data" goes. It was the same as Reset.
  - **Import data** comes in as a new `Api.db.import(bundle)`, backed by the existing `importAll`. Admin only (`database.manage`). It confirms with a typed word, as Reset does.
- **GAP-041, time:**
  - Notes are shown under each entry, on Home and in the Time tab.
  - The CheckInCard task picker gets a **Whole project** option for each project you can log on, which starts a `{ projectId }` timer.
- **GAP-043:**
  - `tickets.projects` goes. `useProjects` reads `projects.list`.
  - Tasks are read through `/api/tasks/...` too, so one REST name is used.
  - `useProject`, `useWorkspace` and `trackLoading` are deleted.
- **GAP-045, live updates:**
  - One realtime client for the app, made in `RealtimeBridge` and handed out by a `useRealtime()` hook.
  - The typing store also drops expired typers, which fixes the every-second re-render deferred from M11.
- **GAP-048, board ranks:** when a drop's gap falls under 1e-6, the target column is renumbered in steps of 1000, in the order shown. Each changed card is sent as its own `{ rank }` patch.

## Review Focus

1. **A drop between two cards with nearly equal ranks, or on a filtered board.** The order must stay what the person sees, and a hidden card never ties. Tests are in Task 9.
